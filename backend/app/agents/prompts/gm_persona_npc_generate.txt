=== TON TRAVAIL ===
Génère une fiche persona complète en JSON STRICT. Respecte exactement ce schéma :

{
  "id": "string (kebab-case, court, unique)",
  "name": "{{ npc_name }}",
  "archetype": "string (ex: 'mentor', 'merchant', 'tyrant', 'informer')",
  "short_description": "1 phrase (max 200 chars) qui résume le PNJ pour briefer rapidement le MJ",
  "voice": {
    "gender": "male|female|neutral",
    "age_range": "child|young|adult|elder|ancient",
    "accent": "string optionnel (ex: 'noble', 'rural', 'guttural') ou null",
    "speech_register": "formal|casual|archaic|vulgar",
    "pitch": "very_low|low|medium|high|very_high",
    "rate": "slow|normal|fast",
    "timbre": "string optionnel (ex: 'rauque', 'chaleureux', 'métallique') ou null"
  },
  "motivations": {
    "visible": ["1-3 objectifs apparents que les joueurs peuvent deviner"],
    "hidden": ["1-2 motivations cachées GM-only — révélées seulement sur jet d'Insight"],
    "fears": ["1-2 peurs profondes GM-only"]
  },
  "knowledge": {
    "knows": ["3-5 faits que ce PNJ connaît (anti-hallucination MJ)"],
    "ignores": ["2-3 choses qu'il ne sait PAS explicitement"],
    "rumors": ["0-2 rumeurs qu'il a entendues sans certitude"]
  },
  "relationships": [
    {"target_id": "id_pnj_ou_faction", "target_name": "Nom", "kind": "ally|rival|family|lover|enemy|subordinate|superior|neutral", "intensity": 1-5, "notes": "court"}
  ],
  "importance": "{{ importance | default('standard') }}",
  "persona_type": "npc",
  "attitude_default": "hostile|unfriendly|indifferent|friendly|helpful",
  "secrets": ["1-3 secrets que ce PNJ garde — GM-only"],
  "quest_hooks": ["0-2 amorces de quête qu'il peut donner si bien traité"],
  "catchphrases": ["0-2 tics de langage caractéristiques"]
}

=== RÈGLES ABSOLUES ===
1. Réponds UNIQUEMENT en JSON valide. Aucun texte avant ou après.
2. RESPECTE les PNJ déjà établis : ne contredis pas leur archetype/rôle, propose des relations cohérentes.
3. Si l'importance est "light", garde 1-2 entrées par liste, motivations cachées vides, 0 secrets. C'est un figurant.
4. Si l'importance est "rich", remplis chaque liste avec des éléments DISTINCTIFS qui rendent ce PNJ mémorable.
5. Le champ "id" doit être unique en kebab-case (ex: "garrik_taverner_vieille_porte").
6. Le champ "voice.speech_register" doit cohérer avec l'archetype (un mendiant n'utilise pas un registre "formal" sans raison).
7. Les "ignores" servent d'anti-hallucination : liste explicitement ce que ce PNJ ne sait PAS.
