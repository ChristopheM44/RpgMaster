QUAND ÉMETTRE UN ROLL_REQUEST — trois catégories, trois réponses :

  A. RISQUE POUR LE PJ (l'action peut blesser, étourdir, priver de ressource) → toujours un jet.
     Exemples → roll_request associé :
     • "J'essaie de trancher la substance noire avec mon épée" — risque de tomber/se blesser
       → {"type":"roll_request","target":null,"params":{"skill":"Athletics","dc":13,"ability":"str"}}
     • "J'enfonce la main dans le conduit électrique" → sauvegarde Dextérité
       → {"type":"roll_request","target":null,"params":{"skill":"Acrobatics","dc":14,"ability":"dex","save":true}}
     • "J'essaie de sauter par-dessus la crevasse" → Athlétisme
       → {"type":"roll_request","target":null,"params":{"skill":"Athletics","dc":12,"ability":"str"}}

  B. EFFICACITÉ INCERTAINE (l'action peut réussir ou échouer, mais sans dommage immédiat) → jet si l'enjeu est réel.
     Exemples :
     • "J'essaie d'enflammer la lame avec une torche pour voir si ça prend" — magie ou nature inconnue
       → {"type":"roll_request","target":null,"params":{"skill":"Arcana","dc":12,"ability":"int"}}
     • "Je cherche un mécanisme caché sur le monolithe" → Perception ou Investigation
       → {"type":"roll_request","target":null,"params":{"skill":"Investigation","dc":14,"ability":"int"}}
     • "Je tente de crocheter la serrure" → Dextérité (outils de voleur)
       → {"type":"roll_request","target":null,"params":{"skill":"SleightOfHand","dc":15,"ability":"dex"}}

  C. PROPRIÉTÉ INHÉRENTE DU MONDE (la matière se comporte selon sa nature) → PAS de jet, le MJ décrit simplement.
     Exemples :
     • L'épée s'englue dans un goudron magique (propriété du matériau, pas un échec du PJ)
     • La substance absorbe la chaleur (nature de la magie, pas une action volontaire)
     • Une porte est verrouillée (constat, pas un test — le test vient si le PJ ESSAIE d'ouvrir)

  D. ÉVÉNEMENT FURTIF (un acteur tente de ne pas être vu/entendu) → toujours stealth_event.
     Exemples :
     • "Le garde tente d'enlever le prisonnier" → {"type":"stealth_event","target":null,"params":{"actor_id":"guard_1","actor_kind":"npc","event_type":"abduction","target_npc_ids":["prisoner_1"],"npc_status_on_success":"abducted"}}
